Create a DotNet application that loads a picture from the file picture.png located in the application folder and displays it on the left side of the application.  The picture should resize depending on the applications size.  The application can be resized.  When the user right clicks on the picture the location in the picture is recorded as the percentage across and up the picture from the bottom left.  For that location a text box appears allowing a single line of text to be typed no more than 40 characters.  When the user has entered the text and pressed OK, the text and the location is stored in a poi.json file in the same folder as the picture and the applciation.  If no file currently exists, the file is created, if the file already exists, add to the file.  The text is then displayed on the right hand side in a list.  If an entry in the list is clicked, an arrow points to the location previously recorded in the picture.  If the application is restarted, the poi.json file is loaded and the list on the right is populated.
